# Comfy Premium — лендінг підписки

Концепт преміального лендінгу підписки Comfy Premium з анімаціями та інтерактивами.
Статичний сайт: один `index.html` + картинки в `assets/`. Збирати нічого не треба.

## Деплой
Vercel → Add New → Project → Import цього репозиторію → Deploy (Framework Preset: Other, без команд збірки).
Кожен пуш у `main` автоматично оновлює сайт.

## Що всередині
- Анімації: GSAP 3.12 + ScrollTrigger, плавний скрол Lenis (підключені з CDN).
- Шрифт Inter (Google Fonts), кольори й компоненти — з ❖ Comfy UI.
- «Сіяшки» на картках сервісів — шейдер Light rays з макета, перенесений на WebGL; без WebGL — CSS-градієнт.
- Сторінка закрита від пошукових систем (`noindex`).
